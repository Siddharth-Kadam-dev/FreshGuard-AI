FreshGuard AI Frontend (beginner-friendly package)

HOW TO RUN
1. Keep index.html, style.css, and script.js in the same folder.
2. Double-click index.html to open it in your browser.
3. Use Register or Login to enter the demo.

FILES
- index.html: the page sections, forms, tables, buttons, and modals.
- style.css: colors, spacing, layout, responsive design, and visual states.
- script.js: behavior and data handling.

JAVASCRIPT OVERVIEW
- Helper functions: select page elements, format dates, create IDs, and escape text.
- Saved data: inventory, usage history, shopping list, and profile are stored in browser localStorage.
- Render functions: refresh the inventory table, alerts, expiry list, usage chart, and shopping list.
- Event listeners: respond to buttons and forms such as add/edit/delete item, record usage, and mark shopping items complete.

NOTE
This is a front-end demo. Login/register is simulated; it does not use a real server or secure authentication. Browser localStorage keeps demo data on this browser. The UI and available sections/features have been preserved.
